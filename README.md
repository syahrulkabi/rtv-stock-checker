# RTV Stock Checker

Free mobile-first prototype for GitHub Pages.

## Prototype
Search `PLYPVV8` to view the sample data.

The prototype uses:
- Fixed stock priority: ONLINE → E33 → DM → WH_SALES → KRMS → PTT
- B / C / Member prices only
- No A price in the client data
- Optional native browser barcode scanning where supported
- PWA manifest/service worker

## Important
This version does **not** connect to the RTV system yet. Do not put RTV usernames, passwords, cookies, or secrets into this repository.

The next stage is a secure API/backend that queries the existing RTV system and returns only the fields the mobile app needs.
